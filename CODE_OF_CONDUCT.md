# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want qiick Excubia to be a welcoming, harassment-free space for everyone. Be respectful, assume good intent, and keep feedback about the work, not the person.

Report unacceptable behaviour privately to the maintainers via the contact on [qiick.io](https://qiick.io) or a private GitHub security advisory. Reports are handled confidentially, and maintainers may remove, edit or reject contributions and ban participants who violate this code.
