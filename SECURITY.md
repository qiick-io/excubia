# Security Policy

## Supported versions

Excubia is pre-release. Security fixes go to the latest `0.x` release.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting ("Report a vulnerability" on the Security tab of `qiick-io/excubia-core`). We aim to acknowledge reports within 72 hours.

Excubia sends only package names and versions to public data sources and never transmits file contents, secrets or `.env` values. Reports showing otherwise are treated as critical.
