# qiick Excubia

Health checks for Laravel apps. In development.

qiick Excubia is the Laravel Health Check CLI of the [qiick](https://qiick.io) suite. The v0.1.0 scope is defined in `docs/SPEC.md` (approved 2026-10-31).

## Install

```bash
composer require --dev qiick/excubia-core
```

The command stays `vendor/bin/excubia`.
